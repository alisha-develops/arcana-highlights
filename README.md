# arcana highlights 

so, where do i even begin?

i went to singapore for my first international hackathon through/by/for hack club and it was genuinely one of those experiences where 48 hours somehow felt like five minutes

i've always liked documenting experiences, but i didn't really want to make another photo dump or a regular travel website. i wanted to do something that felt a little more personal, something that could recreate the feeling of going through an old scrapbook with old game boy camera pictures attached in it and stumbling upon memories you almost forgot about

and that's pretty much how arcana highlights happened!

the idea is to turn the trip into an interactive book, where each page documents a different part of the experience. i've been experimenting with scrapbook layouts, overlapping photographs, little stamps, handwritten style details and animations to make everything feel like an actual collection of memories rather than a bunch of web pages so if i ever miss it in future i can re visit and show it to my family and friends who are lowkey interested in my journey :D

## the building process

this has also been a pretty fun learning experience technically. i'm using typescript, sass and gsap, and i've been figuring out how to make all three work together.

sass is particularly new territory for me. this is my first proper project using it, and i initially wasn't sure how i'd feel about it, but i've actually started enjoying it quite a bit. being able to nest styles and organise everything has made working with the increasingly complicated page layouts much nicer.

gsap has been another big part of the project. i've been using it for the book's entrance, 3D page turning animations, zooming, transitions and even the little typing effects for subtitles. there's been a LOT of trial and error involved, especially when trying to coordinate multiple animations without everything getting in each other's way but i've worked with gsap before so i like it
